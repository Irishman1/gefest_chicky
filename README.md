# Нарізка квартир із плану поверху

`cut_apartments.py` бере план поверху, знаходить кожну квартиру і зберігає її
окремим PNG **на білому фоні** — сусіди й усе зайве прибрані.
(`--bg transparent` — якщо потрібен прозорий фон, `--bg jpg` — JPG.)

Приймає: PDF (векторний або скан) і картинки — PNG, JPG, TIF, BMP, WEBP.
Багатосторінкові PDF обробляються посторінково (сторінка = поверх).

## Встановлення (один раз)

```bash
pip install pymupdf pillow numpy scipy
```

Для сканів і «мертвих» PDF без текстового шару потрібен ще Tesseract OCR:
https://github.com/UB-Mannheim/tesseract/wiki (скрипт знаходить його сам,
або вкажіть `--tesseract "C:\Program Files\Tesseract-OCR\tesseract.exe"`).

## Запуск

```bash
python cut_apartments.py
```

Обробить усі плани в поточній папці, результат — у `output/`,
імена файлів: `12поверх_А-12.1.png`, `12поверх_А-12.2.png` …

Конкретний файл або папка і свої налаштування:

```bash
python cut_apartments.py "Эллада-7 12.08.26 12 поверх.pdf" -o "C:\Планування" --dpi 300
```

Або перетягнути файл плану на `Вирізати квартири.bat`.

## Як воно працює

1. **Підписи квартир.** Спочатку читається текстовий шар PDF (`А-12.1`, `К-3.15`).
   Якщо тексту немає — вмикається OCR по картинці: креслення чиститься від стін
   і ліній, лишається текст, і робиться кілька проходів розпізнавання.
2. **Контур квартири.** У векторному PDF береться сама заливка квартири.
   На скані заливка виділяється за кольором, а стіни ріжуть її на кімнати —
   кімнати збираються назад у квартиру, поки в одному шматку не лишиться
   рівно один підпис. Балкони й лоджії приліплюються до своєї квартири.
3. **Межа.** Маска доростає вздовж ліній креслення (у порожній коридор не
   вилазить), а на спільній стіні дві сусідні квартири зустрічаються посередині —
   межа йде прямо по стіні.
4. **Нічого не ріжеться навпіл.** Кожен цілісний елемент — вентблок, символ
   вікна, сантехніка, шафа — або входить у кадр повністю, або не входить зовсім,
   залежно від того, чия це переважно квартира. Суцільні залиті блоки
   (вентшахти, стовпи) розпізнаються окремо за кольором, бо на кресленні вони
   злиті зі штриховкою стіни.
5. **Контур ортогональний**: спершу зрізаються тонкі «вусики» (дуги дверей,
   виносні лінії розмірів, хвости штриховки) — саме вони давали сходинки на межі;
   далі згладжування квадратним елементом і підгонка під сітку, тож кути
   лишаються кутами, без округлень і «прикусів».
6. **Вхідні двері лишаються видимими**: область, обмежена дугою відчинення,
   полотном дверей і стіною, додається цілком, і межа в цьому місці йде по самій
   дузі — півколом, як на кресленні.
7. Порожнини всередині зашиваються, решта сторінки замальовується білим.

## Ключі

| Ключ | Що робить | За замовчуванням |
|---|---|---|
| `-o, --out` | папка для результатів | `output` |
| `--dpi` | роздільна здатність результату | `300` |
| `--bg` | `white` / `transparent` / `jpg` | `white` |
| `--mode` | `auto` / `vector` / `raster` | `auto` |
| `--dilate` | наскільки маска доростає вздовж ліній, пункти | `16` |
| `--padding` | поле навколо квартири, пункти | `6` |
| `--smooth` | згладжування/вирівнювання контуру, пункти (0 — вимкнути) | `4` |
| `--snap-area` | макс. площа цілісного елемента, який добирається повністю | `3000` |
| `--attach-gap` | на якій відстані балкон вважається частиною квартири | `25` |
| `--min-area` | vector: мін. площа заливки | `300` |
| `--close` | raster: макс. товщина внутрішньої перегородки, пункти | `7` |
| `--sat` | raster: поріг насиченості кольору заливки | `0.06` |
| `--dark` | raster: поріг темряви ліній і стін | `0.45` |
| `--work-dpi` | raster: роздільна здатність аналізу | `200` |
| `--mask-dpi` | роздільна здатність, на якій рахується межа | `150` |
| `--prefix` | літера в номері, якщо шрифт/OCR її не дає | `А` |
| `--floor` | примусовий номер поверху в імені файлу | з підпису або з назви файлу |
| `--name` | шаблон імені: `{floor}`, `{label}`, `{number}` | `{floor}поверх_{label}` |
| `--ocr-tiles` | raster: скільки шматків на бік розпізнавати додатково (1 — вимкнути) | `3` |
| `--tesseract` | шлях до tesseract.exe | шукається сам |

## Наскільки точно

* **Векторний PDF** (як `Эллада-7 … 12 поверх.pdf`) — усі квартири вирізаються
  точно: контур береться з самого креслення.
* **Скан або картинка** — режим `raster` працює, але це запасний варіант:
  номери читає OCR, а межі — за кольором заливки. На щільному плані частину
  номерів OCR не бачить (такі квартири зберігаються як `без_номера_N`), а
  сусідні квартири інколи потрапляють в один файл — тоді допомагає
  `--close 3` (тонше злиття) або `--attach-gap 15`. Одна сторінка скану
  обробляється 2–4 хвилини (OCR у кілька проходів; `--ocr-tiles 1` швидше).
  Якщо є вибір — давайте векторний PDF, результат буде помітно кращий.

## Якщо щось пішло не так

Скрипт друкує по кожній сторінці: режим, скільки знайдено підписів, скільки
квартир зібрано і що не вийшло.

* **«підписів квартир не знайдено»** — немає ні тексту в PDF, ні Tesseract,
  або підписи нестандартні. Формат підпису: літера, дефіс, поверх, крапка, номер.
* **«кольорових заливок квартир не знайдено»** — план чорно-білий, без заливки
  квартир. Спробуйте `--sat 0.03`; якщо заливки немає взагалі — автоматично
  розрізати такий план не можна.
* **«без_номера_N»** — квартиру знайдено, а її номер не прочитався: перейменуйте файл.
* **Не потрапив балкон/лоджія** — збільшіть `--attach-gap` (напр. `40`).
* **Обрізало стіну або елемент** — збільшіть `--dilate` (напр. `40`).
* **Захопило шматок сусіда чи коридору** — зменшіть `--dilate` (напр. `20`).
* **Дві квартири злиплися в один файл** (raster) — зменшіть `--attach-gap` (напр. `15`).
* **Одна квартира розпалась на дві** (raster) — збільшіть `--attach-gap` (напр. `40`).
* **Край занадто «обкатаний» або, навпаки, з дрібними зубцями** — покрутіть
  `--smooth` (менше — точніше по кресленню, більше — рівніше).
* **Елемент на межі зник** — він дістався сусідові; збільште `--dilate`,
  щоб більша його частина потрапляла у цю квартиру.
* **Літера в імені не та** — `--prefix К`.
* **«залишились незакріплені заливки»** — це, як правило, кольорові прямокутники
  легенди («умовні позначення»), їх різати й не треба.
